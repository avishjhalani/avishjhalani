## 🚀 Featured Engineering Projects

<details open>
<summary><b>⚡ PowerPilot AI — Autonomous Agentic Power BI Dashboard Compiler (Flagship)</b></summary>
<br/>

> Autonomous agentic data pipeline that ingests raw datasets, extracts statistical profiles, synthesizes production DAX measures, and compiles full Power BI dashboards end-to-end.

- **Tech Stack:** `Python` • `FastAPI` • `DuckDB` • `Polars` • `Groq LLM (gpt-oss-120b)` • `Docker`
- ✨ **Key Architectural Achievements:**
  - Ingests and profiles **500,000+ records in 8.6 seconds** at **<35MB peak RAM** via zero-copy DuckDB query execution and out-of-core streaming Polars DataFrames.
  - Built an LLM-driven semantic modeling agent (`Groq gpt-oss-120b`) that synthesizes 6–8 production-grade DAX measures from natural-language business goals within a strict 4,000-character context budget.
  - Designed a sandboxed execution layer with **AST-based static code analysis** blocking unauthorized system calls, backed by a 3-attempt autonomous error-recovery loop (**zero unsafe executions**).
- 🔗 **Links:** [Live Application](https://powerpilot-ai-y758.onrender.com/) • [GitHub Repository](https://github.com/avishjhalani/PowerPilot-AI)
</details>

<details open>
<summary><b>📝 Collab-Docs — Real-Time Collaborative Workspace with CRDTs</b></summary>
<br/>

> A production-grade real-time collaborative document editor powered by conflict-free replicated data types and distributed WebSockets.

- **Tech Stack:** `React` • `NestJS` • `Yjs CRDTs` • `Socket.io` • `PostgreSQL` • `Redis Pub/Sub` • `Prisma` • `Docker`
- ✨ **Key Architectural Achievements:**
  - Real-time collaborative synchronization across Vercel, Render, and Supabase achieving an average **~327ms round-trip sync latency** across continents.
  - Slashed PostgreSQL write overhead by **98%** by replacing per-keystroke writes with a custom 5-second debounced state-save buffer.
  - Reduced network payload by **90%+** by broadcasting compressed binary Yjs deltas (30–60 bytes/frame) across multi-instance nodes using a Redis Pub/Sub sync adapter.
- 🔗 **Links:** [Live Application](https://collabdocs-ten.vercel.app/) • [GitHub Repository](https://github.com/avishjhalani/Collab-Docs)
</details>

<details open>
<summary><b>🩸 BloodLink — Geospatial Blood Donor Matching Platform</b></summary>
<br/>

> A full-stack healthcare platform matching emergency blood requests to verified donors within a 10km radius using spatial database queries.

- **Tech Stack:** `Next.js` • `NestJS` • `PostgreSQL` • `PostGIS` • `Redis` • `Prisma` • `JWT` • `Nodemailer`
- ✨ **Key Architectural Achievements:**
  - Implemented proximity-based donor geolocation using **PostGIS spatial indexing** (`ST_DWithin`, `ST_Distance`) for instant radius filtering.
  - Verified reliability and edge-case resilience with an **11-case E2E test suite** (Jest/Supertest) covering the complete lifecycle from request creation to donor fulfilment.
  - Secured user auth via JWT tokens delivered in **httpOnly, sameSite cookies** to prevent XSS-based credential extraction.
- 🔗 **Links:** [Live Application](https://bloodlink1.vercel.app/) • [GitHub Repository](https://github.com/avishjhalani/BloodLink)
</details>

<details>
<summary><b>📨 Notification Service API — Scalable Asynchronous Queue System</b></summary>
<br/>

> Production-grade background notification worker pipeline handling bulk email dispatch with queuing and rate limiting.

- **Tech Stack:** `NestJS` • `PostgreSQL` • `Redis` • `BullMQ` • `Prisma` • `Docker` • `JWT` • `Resend`
- ✨ **Key Architectural Achievements:**
  - Sub-300ms API response times achieved by offloading delivery jobs to a Redis-backed background worker with BullMQ.
  - Automatic retry with exponential backoff strategy (5s → 10s → 20s) for fault-tolerant network recovery.
  - Per-client JWT token rate limiting at 5 req/min with HTTP 429 throttling to prevent abuse.
- 🔗 **Links:** [GitHub Repository](https://github.com/avishjhalani/notification-service)
